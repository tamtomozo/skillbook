# スキルブック・ハンター

トレジャーハンターが古代遺跡の最深部（地下10階）にある秘宝を目指す、見下ろし型アクションRPG。
TypeScript + Vite 製。画像ファイルは使わず、キャラクターや地形はすべてキャンバスのパスとグラデーションで描いています。

## 起動

```sh
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 型チェック + dist/ へビルド
```

## ゲームの仕組み

- **体力・MP**: どちらも上限100で固定。スキルブックと装備で強くなる。
- **パラメタ**: 攻撃力（通常攻撃と剣・弓・盾の技の威力）、魔力（杖の攻撃と魔術の威力）、防御力（受けるダメージ倍率 = 50 / (50 + 防御力)。盾の技の威力にも効く）、運（会心の一撃の確率 = 5% + 運×0.5%（最大50%）でダメージ1.5倍、敵のアイテム・鉱石ドロップ率 ×(1 + 運/40)、敵のゴールド +運%）。HUDに表示され、窮地の効果で上がっているときは赤く光る。
- **経験値 → SP**: 敵を倒して得たEXPを、スキルブック画面でSPに変換する（変換するたびに必要EXPが増える）。
- **スキルブックのレベル**: 本は手に入れた時点で Lv0（効果なし・技も覚えていない）。SPを使ってレベルを上げる（必要SP：Lv0→1 は 1、それ以降は今のレベル）。初級は Lv3、中級は Lv4、上級は Lv5 まで。
- **スキルブックの3系統**（定義は `src/skills.ts`）
  - **パラメタの書**: 剛力（攻撃力）・叡智（魔力）・堅守（防御力）・幸運（運）の書 × 初級/中級/上級。レベル1つごとに +2 / +3 / +4。
  - **技の書**: 剣技・弓術・魔術・盾術の書 × 初級/中級/上級。決まったレベルで技を覚える。**剣の技は剣、弓の技は弓、魔術は杖、盾の技は盾を装備しているときだけ使える**。アクティブな技はホットバー(1〜5)に自動でセットされ、MPを消費して使う。
  - **窮地の書**: 体力が一定以下で発動。背水（攻撃力%UP）・不屈（防御力%UP）・覚醒（魔力%UP）・捨て身（防御力を攻撃力に加算）・魔盾（魔力を防御力に加算）・起死回生（運%UP）。レベルで効果量が上がる。
  - **2段階の書**（剣技・弓術・魔術・盾術の「二段」、地下5階から宝箱）: Lv1 で1段目、Lv3 で2段目の技を覚える。1段目の技を使うと「状態」に入り、**そのフロアにいる間**（階段を降りる・町へ戻る・倒れるまで）続く。状態のあいだはパラメタが 15% 上がり（鷹の構えは会心率 +15%）、2段目の大技がクールタイムごとに何度でも使える。状態でないときの2段目はホットバーで暗くなる。
    - 剣：剣気解放 → 斬鉄閃（貫通する斬撃3本）／弓：鷹の構え → 流星射（貫通する矢5本）／魔術：魔力覚醒 → メテオ（近くの敵3体に隕石）／盾：守護の誓い → 審判の盾（周囲に衝撃波＋2秒ひるみ）
- **本の入手**: 最初は『剣技の書・初級』（Lv0）と SP 3 を持っている。初級は道具屋、中級は地下3階に到達すると道具屋に入荷。上級と窮地の書はダンジョンの宝箱から見つかる。
- **呪われた本と神殿**: ダンジョンの宝箱で拾った本は呪われていて、「呪われた書 #n」としか表示されず、正体も効果も分からない（かばんの枠は使わない）。町の「神殿」でお金を払って浄化すると正体が分かり、Lv0 から使えるようになる。代金は本の系統で変わり、パラメタの書 150 G（弱い呪い）・窮地の書 250 G（強い呪い）・技の書 350 G（とても強い呪い）。神殿では呪いの強さと代金が見えるので、正体の手がかりになる。
- **同じ本と買い取り**: 宝箱からは持っている本と同じ本も出る。浄化して同じ本だと分かると「予備」になる。道具屋の「本を売る」タブで、予備や使っている本を売れる。買い取り値は、店の本は売値の半額、遺跡の本はパラメタ 300 G・窮地 400 G・技 500 G。使っている本を売ると、上げるのに使ったSPは全部戻り、その本の技は忘れる（予備があれば予備が Lv0 で残る）。最初の『剣技の書・初級』は売れない。売った本は、また買ったり宝箱で見つけたりできる。
- **鍵付きの宝箱**: 誰でもこじ開けられる。中身が豪華。
- **旧セーブ**: スキルブックが3系統になる前のセーブを読み込むと、本は『剣技の書・初級』に入れ替わり、本のレベル上げに使ったSPと道具屋で本を買った代金が戻る。
- **持ち歩けるのは3冊まで**: 残りは町の「わが家」の本棚にしまい、本棚の前で入れ替える。本棚にある本のスキルは、習得済みでも使えない（パッシブも無効）。かばんが満杯のときに手に入れた本は、自動で本棚へ送られる。
- **武器防具屋**: 武器は剣・弓・杖・盾の4種類。剣・弓は攻撃力、杖は魔力、盾は防御力（と少し攻撃力）、鎧は防御力を上げる。通常攻撃は武器で変わる（剣：斬る／弓：矢／杖：魔力の弾／盾：盾で殴る）。地下3階・6階に到達すると上位品が入荷。店の「鍛冶場」では、持っている武器・防具を代金と鉱石で最大 +5 まで鍛えられる（店先では親方が金床を打っている）。「装備を売る」タブでは、装備中でない武器・防具を売れる（売り場の値段と鍛えるのに払った代金の合計の半額。鉱石は戻らず、鍛えた分はなくなる。最初の短剣と服は売れない）。定義は `src/equipment.ts`。
- **魔物の素材と武器作成**: 魔物は倒すと 22%（ゴーレムは 50%。運で上がる）で素材を落とす（スライム→スライムゼリー、コウモリ→コウモリの翼、ゴブリン→ゴブリンの牙、スケルトン→古びた骨、ゴースト→霊気の結晶、ゴーレム→ゴーレムの核）。武器防具屋の「装備作成」タブで、素材・鉱石・代金から店では買えない武器と防具を作れる（作るとそのまま装備）。作った装備も鍛冶場で鍛えられ、売ることもできる。
  - 吸血の剣（地下3階〜）：攻撃を当てるたびに体力 +2 ／ 白骨の弓（地下3階〜）：通常攻撃の矢が貫通 ／ 霊魂の杖（地下4階〜）：敵を倒すと MP +5 ／ 巨像の盾（地下6階〜）：体当たりしてきた敵に防御力ぶんのダメージを返す
  - 夜翼の外套（地下2階〜）：移動速度 +15% ／ 骸骨の鎧（地下3階〜）：敵を倒すと体力 +3 ／ 霊布の衣（地下4階〜）：敵の飛び道具のダメージが半分 ／ 巨像の鎧（地下6階〜）：吹き飛ばされず、受けるダメージ -10%
- **鉱石**: 遺跡の部屋の壁ぎわにある鉱脈を [E] で3回たたくと、2〜3個こぼれ出る。敵（ゴーレムは高確率）や宝箱からも出る。+1〜+2 は鉄鉱石（地下1階〜）、+3〜+4 は魔法銀鉱（地下3階〜）、+5 は竜炎石（地下6階〜）。
- **わが家**: 冒険は家から始まる。ベッドで休むと全回復＆セーブ。

## 描画の軽さ

- **解像度の自動調整**: 50fps を下回る状態が約3秒続くと、描く解像度の倍率を一段下げる（2倍 → 1.75 → 1.5 → 1.25 → 1倍）。下げたことはログに出る。プレイ中は戻さない（ページを読み込み直すと最大から始まる）。画面のリフレッシュレートが低い環境で誤って下げないよう、いちばん短いフレーム間隔の 1.25 倍も基準にしている（`Game.watchFrameRate`）。
- **被弾の白い点滅・残像**: `ctx.filter` は図形ごとに処理が走ってとても重いので使わない。影を除いた姿を小さな作業用キャンバスに描いて白く塗り、1枚の画像として重ねる（`art.ts` の `drawWhite`）。
- **暗闇**: 幅 960px 以下の画像に描いて、画面いっぱいに引き伸ばす。
- **町の建物**: 動かない部分は拡大率ごとに一度だけ画像に描いて使い回し、鐘・煙・火の粉・親方など動く部分だけ毎フレーム描く。画面の外の建物は描かない。

## 操作

| キー | 動作 |
| --- | --- |
| WASD / 矢印 | 移動 |
| Space / J | 攻撃（長押しで連続攻撃） |
| 1〜5 | スキル使用 |
| E / Enter | 調べる・宝箱・階段・お店 |
| K / Tab | スキルブック |
| Q / R | 回復薬 / エーテル |
| Esc | ヘルプ・閉じる |

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `src/game.ts` | ゲームループ、移動・戦闘・スキル効果・描画 |
| `src/skills.ts` | スキルとスキルブックの定義（バランス調整はここ） |
| `src/entities.ts` | プレイヤー・敵の定義とステータス |
| `src/map.ts` | 町のマップとダンジョンの自動生成 |
| `src/art.ts` | キャラ・敵・宝箱・アイテムの絵（横・正面・背中の3方向。左向きは横向きを反転） |
| `src/terrain.ts` | 地面の模様・壁・道・池・木・建物・灯り |
| `src/home.ts` | わが家の室内（床・壁・暖炉・本棚・ベッドなど） |
| `src/ui.ts` / `src/style.css` | HUD・スキルブック・道具屋などの画面 |
| `src/state.ts` | セーブデータ（localStorage）。呪われた本は `cursed` に入る |
